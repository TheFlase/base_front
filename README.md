# 🎓 前端学习完整项目集

这是一个完整的前端学习路线项目集合，包含从基础到进阶的所有阶段的实战项目。

│

## 🚀 快速开始

### 环境准备
```bash
# 安装 Node.js（推荐 v18+）
# 下载地址：https://nodejs.org/

# 验证安装
node -v
npm -v
```

### 从第一个项目开始
```bash
# 进入 HTML + CSS 基础项目
cd 01-html-css-basics/personal-resume

# 使用浏览器打开 index.html
# 或使用 VSCode 的 Live Server 插件
```

### 学习建议
1. **按顺序学习**：从第一阶段开始，逐步深入
2. **动手实践**：每个项目都要亲自编写代码
3. **理解原理**：不要只是复制代码，要理解为什么这样写
4. **自主扩展**：完成基础功能后，尝试添加新功能
5. **代码复盘**：定期回顾之前的项目，重构代码
