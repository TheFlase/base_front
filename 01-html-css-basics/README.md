# 阶段1：HTML + CSS 基础

## 学习目标

- 掌握 HTML5 语义化标签
- 理解 CSS 盒模型和定位
- 熟练使用 Flexbox 和 Grid 布局
- 掌握响应式设计原理
- 学会使用 CSS3 动画和过渡

## 项目列表

### 1. 个人简历页面（personal-resume）
**难度**：⭐⭐  
**学习要点**：
- HTML 语义化标签（header, nav, section, article, footer）
- CSS 基础样式（颜色、字体、间距）
- Flexbox 布局
- 基础动画效果

**功能特性**：
- 个人信息展示
- 技能清单
- 工作经历时间线
- 项目展示
- 联系方式

### 2. 响应式布局练习（responsive-layout）
**难度**：⭐⭐⭐  
**学习要点**：
- 媒体查询（Media Queries）
- Grid 布局系统
- 移动优先设计
- 弹性图片和视频
- 响应式导航菜单

**功能特性**：
- 三种布局模式（桌面、平板、手机）
- 响应式图片画廊
- 汉堡菜单
- 卡片布局

## 开始学习

```bash
# 进入项目目录
cd 01-html-css-basics

# 选择一个项目开始
cd personal-resume

# 使用浏览器打开 index.html
# 或使用 VSCode 的 Live Server 插件
```

## 学习时间建议

- 全职学习：2-3 周
- 业余学习：1-2 个月
- 每天学习时间：2-4 小时

## 学习资源

- [MDN HTML 教程](https://developer.mozilla.org/zh-CN/docs/Web/HTML)
- [MDN CSS 教程](https://developer.mozilla.org/zh-CN/docs/Web/CSS)
- [Flexbox Froggy](https://flexboxfroggy.com/)（Flexbox 游戏）
- [Grid Garden](https://cssgridgarden.com/)（Grid 游戏）

## 项目扩展建议

完成基础项目后，可以尝试：
- 添加深色模式切换
- 使用 CSS 变量管理主题
- 添加更复杂的动画效果
- 创建自己的个人网站
- 仿制知名网站的布局（如 Apple、Google）
